---

oboku app being a website first you can and should use it by visiting [https://app.oboku.me](https://app.oboku.me). Once you visit the website you have then two choices, you can either stay and use it with your favorite internet browser, or you can **install it to your home screen**.&#x20;

:::note
Remember that oboku is an **offline first app**. It means that after opening it for the first time, you can open it and use it whether you have internet connection or not. All your changes will be sync later with your other devices. This really is not much different from a native app.
:::

By installing the app to your home screen you will be able to open it the same way as you would open a native app (by tapping its icon) and take benefit of the **fullscreen mode**.

## Install the app

In Chrome, Edge and other Chromium browsers, on a computer or an Android device, oboku can start the install itself. Open **Profile** and select **Install the app** in the **Device** section, then confirm in the browser's dialog. The action appears only when the browser can install oboku, and it goes away once oboku is installed.

In other browsers, such as Safari and Firefox, and in every browser on iPhone and iPad, use the browser's own menu. In Safari on iPhone and iPad, it is **Add to Home Screen** in the share menu.

Depending on your browser, device brand and version **the option to install it to home screen might not be available**. In this case you can use the native app version (see below).

**For more information about device compatibilities please visit the dedicated wiki section.**

## Native App

:::caution
Native app are not yet available on the store, if you want to try them out you can access it at this [shared drive](https://drive.google.com/drive/folders/1yPpzwMW6PFw3g9P_ed82M4jzvQZxhioG?usp=sharing). If you have issue with it please contact us.
:::

Using oboku should be as convenient as using a native app and in most case scenario you should be able to install the web app to your home screen. However it is not always possible on every devices such as old phones, old internet browser, or **eBook readers.** For these devices you can use the App Store version which is in fact a native app wrapping the web app. The experience should remain the same.

## **Why don't you have official native apps?**

Development is costly, the web is cool and works mostly everywhere. So far there are no technical limitation known by making it web based. The only problem is for devices that have either broken, outdated or no web browser at all (remarkable, kobo, etc). Developing a native app for these devices would require an entire new development and we just don't have the resources yet. If you feel like helping doing it, your help would be much appreciated.
