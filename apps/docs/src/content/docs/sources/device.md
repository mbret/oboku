---
title: "Device"
---

You can add the books stored on your phone, tablet or computer. To add them, select **Add a new book** in your library, then **From Local file**. You can also drag the files onto the app.

## What is supported

- The [formats oboku can read](/guides/supported-contents).
- Several books at once. A library sync cannot use the device.

## Where the file is kept

The book file stays on the device that added it. Your library, the book's reading progress and its annotations sync to all your devices, but only the device that added the book can open it.

oboku cannot download the file again. If you remove the book's download from that device, or clear oboku's data in its browser, the file is lost. To read a book on all your devices, add it from a source such as [Google Drive](/sources/google-drive) or [Dropbox](/sources/dropbox).
