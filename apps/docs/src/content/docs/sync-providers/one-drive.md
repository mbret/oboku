---
title: "One Drive"
---

Microsoft One Drive is fully supported and works similarly to Google Drive or Dropbox.

## Sync Reconciliation

Because One drive uses unique ID, moving files around is usually completely safe and oboku will never create duplicates. There is nothing specific you should be careful with.

## Limitations

oboku syncs only the folders and files you pick, as with Google Drive. A folder you pick does not add the files inside it, so pick those files too. On a computer, the picker selects many items at once.
